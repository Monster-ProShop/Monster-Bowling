# Monster Bowling Registration App

A fast, single-page application built for bowling tournament registrations, handling dynamic bracket math and event configurations.

## Features
* **Built-in Bracket Math:** Automatically calculates 1st and 2nd place payouts for 8-person brackets based on custom buy-ins, rounding securely to the nearest $5.
* **Modern UI:** Styled with Tailwind CSS for a responsive, sporty interface.
* **Extensible:** pure HTML/JS structure.

## Next Steps
1. Open `index.html` in any browser to view the interface.
2. Connect the submission button in `app.js` to your preferred backend (e.g., Supabase endpoints, or via a webhook to Google Sheets) to persist bowler specs and configurations.
